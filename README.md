## Featured project

### [Opinion Dynamics Simulation](https://github.com/Arianeshunm/opinion-dynamics-simulation)

A grid-based Python simulation exploring how local interactions influence opinion consensus and segregation.

- Model opinion changes and agent movement using configurable thresholds.
- Visualise how the grid evolves over time with Matplotlib.
- Measure neighbourhood similarity and analyse connected groups with flood fill.
- Check core simulation behaviour with automated tests.

**Tools:** Python · NumPy · Matplotlib · pytest
